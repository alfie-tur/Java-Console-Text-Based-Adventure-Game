This project is meant to be a collection of everything I have learned about Java thus far. It is a place for me to put my skills into practice, instead of just doing simple examples to refer back to. 
This project is going to take inspiration from D&D 20 sided dice, which will be used to calculate all sorts of different things such as total attack damage

Planned features are:
Purchase supplies,
Item Bag for encounters,
Set up camp using supplies,
Infinitely running code until you decide to end it,
Various enemies to randomly encounter,
Companion system where you can have a companion to assist you,
Multiple enemies in one encounter
