To run the game, download TextAdventureGame.jar and make sure you have at least Java version 21 installed. Then open you command window to the location of the file and run "java -jar TextAdventureGame.jar" and it will run the game in your command window

This project is meant to be a collection of the majority of what I have learned about Java so far. It is a place for me to put my skills into practice, instead of just doing simple examples to refer back to. 
This project is going to take inspiration from D&D 20 sided dice, which will be used to calculate various things such as total attack damage
